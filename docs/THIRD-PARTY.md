# Third-party software

- RNNoise v0.2 (Xiph.Org and contributors), BSD-3-Clause: https://github.com/xiph/rnnoise/tree/v0.2. See `third_party/RNNoise.txt`. The default model is distributed by Xiph as generated C under the upstream project license; the build pins its archive hash.
- miniaudio 0.11.25 (David Reid and contributors), MIT-0 option: https://github.com/mackron/miniaudio/tree/0.11.25. See `third_party/miniaudio.txt`.
- The RalpQuiet loopback driver bundles are build-time configurations of BlackHole v0.7.2 (Existential Audio, Inc.), GPL-3.0: https://github.com/ExistentialAudio/BlackHole/tree/v0.7.2. See `third_party/BlackHole.txt`. This project supplies its own device IDs, names, and bundle metadata. No BlackHole application branding or artwork is bundled. The scripts and pinned upstream revision provide the source to reproduce each bundle.
- [VoxLock](https://github.com/arbazsiddiqui/voxlock) v1.3 streaming model by Arbaz Siddiqui, Apache-2.0. The build uses the `onnx/v2` models at Hugging Face revision `2413b292bc2c337bfc19a9802aaf3e011e68e9c4`. See `third_party/VoxLock-LICENSE.txt` and `third_party/VoxLock-NOTICE.txt` for the REAL-TSE/WeSep provenance. RalpQuiet's C++ overlap-add implementation follows the upstream streaming design. No third-party benchmark audio is distributed.
- [ONNX Runtime 1.32.0](https://github.com/microsoft/onnxruntime/tree/v1.32.0), MIT and bundled dependencies. The C API runtime is dynamically linked. See its license and notices in `third_party/`.
- [WebRTC Audio Processing m155.8059.4.0 build](https://github.com/Sqhh99/webrtc-audio-processing/tree/m155.8059.4.0), BSD with accompanying notices and patent grant. The build script pins the arm64 artifact and installs it as a separate library. See the WebRTC, Abseil and PFFFT notices in `third_party/`.

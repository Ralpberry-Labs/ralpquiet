The public SDK describes operating requirements, model variants and latency. It does not publish the current proprietary models, their training recipe or enough detail to reproduce the filtering exactly. The correct comparison is therefore observable output on the same inputs and devices.

## Implementation choices

- [RNNoise](https://github.com/xiph/rnnoise) is a lightweight recurrent model that preserves generic speech. [DeepFilterNet](https://arxiv.org/abs/2305.08227) and [DPDFNet](https://github.com/ceva-ip/DPDFNet) are candidates for a stronger generic model; neither is inherently personalized.
- A voice-activity classifier, even one conditioned on the target speaker, cannot remove a second talker while the target is also talking. A waveform separator can. [Personalized PercepNet](https://arxiv.org/abs/2106.04129) and [REAL-TSE](https://github.com/REAL-TSE/wesep-real-tse) show two approaches.
- [VoxLock](https://github.com/arbazsiddiqui/voxlock) builds on a causal REAL-TSE model and provides streaming graphs. Enrollment derives speaker features from a reference; the causal network uses those features and carries state between chunks. We use explicit enrollment so a colleague or TV cannot be accidentally selected by an initial loudness heuristic.
- The [VoxLock paper](https://arxiv.org/abs/2610.40727) reports an ASR-based comparison using the [Krisp voice isolation dataset](https://huggingface.co/datasets/Krisp-AI/VoiceIsolation-Benchmark-Dataset). Those are upstream numbers for particular runners and model versions. They do not establish RalpQuiet’s live call latency, perceived quality, or effect on your voice.
- A later echo implementation should use the actual playback reference, measure capture/render alignment and avoid suppressing local speech during double talk. Krisp’s SDK recommends capture AEC before noise cancellation. Evaluate it independently with loopback sweeps and conversational audio.
